# FocusCapture v2.0 产品需求文档（PRD）

> **版本**: v0.2（需求已收齐）
> **日期**: 2026-08-09
> **状态**: 需求收齐，待开发
> **关联**: GitHub pengjie1115/FocusCapture（MIT，v0.1.0 已开源）

---

## 1. 背景与目标

FocusCapture v0.1.0 是 WPF .NET 8 本地专注力工具：悬浮球 + 剪贴板捕捉 + 灵感速览 + 导出 + 沉浸记录 + 本地语音识别（FireRedASR2，纯 C# 无 Python 依赖）。

**v2.0 核心目标**：为「灵感速览」注入 AI 能力（翻译 / 搜索 / 问答），把"被动记录"升级为"主动理解"。用户捕捉到的内容（尤其是陌生单词、外文段落）可以就地理解，不必切换到外部工具。

**明确暂缓**（本版本不做）：登录账号体系、后端存储、云同步。

## 3. 用户场景

1. **查词场景**（高频）：捕捉到一条笔记是陌生英文单词，想立刻知道意思 → 右键/选中 → AI 翻译，秒出释义
2. **理解场景**：捕捉到外文段落/技术片段，需要整段翻译或解释 → AI 翻译/搜索
3. **追问场景**：对某条笔记想深入追问（"这段话的背景是什么"）→ AI 翻译/搜索板块内连续对话
4. **全局问答场景**：不针对任何笔记，随手问任何问题 → AI 问答全局入口（面板标题栏 / 悬浮球右键）

## 4. 功能需求

### 4.1 笔记编辑（P0）

**现状**：灵感速览面板中笔记只读展示。

**需求**：
- 默认只读显示，视觉样式不变
- **双击鼠标左键**进入编辑模式，笔记内容变为可编辑文本框
- 编辑模式下支持**文字选中**
- 编辑完成点击**保存按钮**保存；支持 **Ctrl+S 保存、Esc 取消**
- **沉浸式输入锁定**：笔记来源为沉浸式输入同步时，沉浸式输入**未关闭前不可编辑**，触发编辑操作弹窗提示
- 锁定规则统一覆盖：**编辑 + AI 回填**均受沉浸式锁定约束

**实现注意**：
- 非编辑态用 TextBlock（无需文字选中能力）；编辑态切换为可编辑控件
- "双击进入编辑"需自行处理 MouseDoubleClick 事件（只读控件双击默认行为是选中单词）

### 4.2 灵感速览面板 UI 改动（P1）

**当前问题**：面板不实时刷新；日期显示在标题栏；多选删除按钮仅在点击全选/反选后出现；无多天记录查询入口。

#### 4.2.1 刷新按钮

- 标题栏右侧加刷新按钮，点击重新加载面板内容
- 面板打开时、焦点回到面板时**自动刷新**一次（刷新按钮为兜底）

#### 4.2.2 日历热力图（多天记录查询）

- 标题栏日期改为**日历按钮**，点击弹出日历弹窗
- 日历为**单月视图**，支持月份翻页切换（"最长支持一个月"= 单月视图，非回溯范围限制）
- 有笔记的日期在日历上标注，笔记数量以**热力图**呈现，4 档：
  - 0 条 = 灰色
  - 1-2 条 = 浅色
  - 3-5 条 = 中色
  - 6+ 条 = 深色
- 点击日期**立即刷新**下方笔记列表（无"应用"按钮）
- 日历弹窗内提供"今天"快捷跳转按钮（**不放标题栏**）
- 面板关闭后重新打开，默认显示**当天**笔记内容

#### 4.2.3 多选删除

- 任一 checkbox 被勾选（手动勾选/全选/反选）即显示"删除已选"按钮
- 全部取消勾选则隐藏按钮
- **删除笔记时同步删除对应 MD 文档**（选项 A）——注意与 4.6 的边界：编辑/回填走"MD 只增不减"，整条笔记删除走"MD 一起删"

#### 4.2.4 标题栏布局（解读 1）

- 标题栏**不直接显示日期文字**
- 布局：左 = "灵感速览"标题 + 日历按钮；右 = 刷新 + AI 问答入口 + 导出 + 关闭
- 日期信息通过日历弹窗查看

#### 4.2.5 主题配色统一

- v2.0 全部新增 UI 元素（日历弹窗、AI 对话框、浮动工具条、输入面板等）统一跟随灵感速览面板主题色
- 背景/文字/热力色需保证对比度，可读性优先（用户明确：不要看不清）

### 4.3 AI 三板块（P1）

三个常驻功能：**AI 翻译、AI 搜索、AI 问答**。

#### 4.3.1 触发方式

| 状态 | 触发方式 | 作用对象 |
|---|---|---|
| 非编辑状态 | 鼠标右键弹出菜单（保留复制/编辑/删除等原生操作，AI 三选项挂菜单内） | 整条笔记 |
| 编辑状态 | 选中文字后，延迟 300-500ms 浮现**浮动工具条**（点按触发，不打断普通选中/复制） | 选中的文字内容 |

#### 4.3.2 各板块定位

| 板块 | 定位 | 作用对象 |
|---|---|---|
| AI 翻译 | 翻译/解释选中内容或整条笔记 | 单条笔记 |
| AI 搜索 | 搜索并解释笔记内容（纯 LLM 解释，无联网） | 单条笔记 |
| AI 问答 | **全局入口**，可问任何问题，直接调用大模型 | 无绑定（不针对某条笔记） |

#### 4.3.3 AI 问答额外入口

- 灵感速览面板**顶部标题栏**常驻入口
- **桌面悬浮球右键菜单**增加入口（FloatBall）
- **系统托盘图标右键菜单**增加入口（NotifyIcon）

#### 4.3.4 对话框与连续对话

每个板块点击后打开**对话框**（弹窗聊天界面）：
- 消息列表 + 输入框 + **流式输出**（打字机效果，必须支持，否则用户以为卡死）
- **连续对话**：多轮上下文保持
- **上下文裁剪**：保留最近 N 轮对话（防止 token 累积失控）
- 对话历史存**本地 SQLite**
- 会话关系：
  - AI 问答 = 全局长对话，历史持久化保留
  - AI 翻译 / AI 搜索 = 围绕当前笔记的短对话，关闭对话框即清（或保留最近会话）
  - 三个板块**不共用**同一上下文，防止串味

#### 4.3.5 提示词设计

**动态适配，不写死**：
- 选中内容为**短词**（单词/短语）→ 词典式释义：词性 / 释义 / 例句
- 选中内容为**长文**（段落）→ 整段翻译 + 简要解释
- 判定规则：按内容长度/是否含空格分词数阈值切换

### 4.4 回填机制（P1）

**默认追加，不覆盖**——原始捕捉内容是一手资料，覆盖即信息丢失（且无版本历史）。

- 追加格式：原文 + 换行 + `【释义/翻译】AI 结果`
- 回填内容带**来源标记**（如"AI 释义"），用户可区分捕捉内容与 AI 补充
- 提供三选一：**追加（默认）/ 覆盖（二次确认弹窗）/ 不修改仅复制到剪贴板**
- 回填受**沉浸式锁定**约束（锁定中的笔记不可回填）
- 对话框内每条 AI 回复提供"回填到笔记"按钮（针对当前笔记）

### 4.5 模型接入（P0 基础设施）

#### 4.5.1 LLM Provider 抽象层

- **模型选择权交给用户**（设置页可切换）
- 抽象接口定义：聊天补全（含流式）、工具调用（tool calling，**预留位**，本次联网不做但接口要留）

#### 4.5.2 协议支持

- **先只做 OpenAI 兼容协议**（Chat Completions），覆盖绝大多数免费模型（Agnes/混元/DeepSeek/智谱/Kimi）
- Anthropic Messages 协议**后置**，抽象层预留协议扩展位

#### 4.5.3 预置模型模板

| 模型 | Base URL | 说明 |
|---|---|---|
| Agnes 2.5 Flash（默认） | `https://apihub.agnes-ai.cn/v1` | 不限期免费、512K 上下文、支持 tool calling、国内节点 |
| Hunyuan-lite | 腾讯云混元 | 永久免费，兜底 |

#### 4.5.4 API Key 策略（BYOK）

- 用户自带 Key，在「设置 → AI 模型」配置页填写
- 内置模型模板（预填 Base URL + 模型名），用户只需填 Key
- **不内置共享 Key**——泄露被薅会导致账号封禁
- 设置页明示：笔记内容将发送至用户配置的模型服务

### 4.6 MD 文档回溯机制（方案 B：原始快照 + 折叠日志）

**定位**：MD 文档 = 历史档案（不可变账本），当前状态以灵感速览面板为准。

**现有机制**（v0.1.0 延续）：每次新建/捕捉笔记默认生成一个 MD 文档，内容写入后与面板笔记不同步，作为回溯兜底。

**v2.0 扩展规则（只增不减）**：

- 灵感速览中**追加**内容（AI 回填、手动编辑新增）→ MD 文档同步
- 灵感速览中**删减**内容 → MD 文档不删（保持原样）
- 记录"发生过删除"≠ 删除 MD 内容

**MD 文档结构**：

```markdown
# 笔记标题（捕捉于 yyyy-MM-dd HH:mm）

## 原始捕捉内容
（捕捉时的完整内容，永远不修改）

<details>
<summary>变更记录（共 N 条）</summary>

### yyyy-MM-dd HH:mm 手动编辑
- 新增：xxx

### yyyy-MM-dd HH:mm AI 回填
- 追加：【释义】xxx

</details>
```

**规则明细**：

| 操作 | MD 文档行为 |
|---|---|
| 捕捉新建 | 写入原始内容快照 |
| AI 回填（追加） | 变更记录区追加条目（时间戳 + 来源 + 内容） |
| 手动编辑新增 | 行级对比提取新增行，追加变更记录条目 |
| 手动编辑删减 | 原始区不动，变更记录标注"删除：xxx" |
| 替换 | 变更记录记 `- 旧内容 / + 新内容`，原始区不动 |

**实现要求**：
- 变更记录追加式写入，只增不减
- 保存时做**行级对比**，只提取新增行写入日志（不做全文 diff）
- 变更记录条目带时间戳 + 来源标记（手动编辑 / AI 回填）
- 变更记录区用 `<details>` 折叠，默认收起保持可读性

### 4.7 查词/解释接口抽象（P0 架构）

- 定义 `ITextExplainService` 接口：输入文本 → 输出释义/翻译
- 首个实现 = LLM 实现（走 Provider）
- 本地词库（如 ECDICT）后续作为新实现插拔，UI/业务层零改动
- **要求**：业务代码不得直接调用 LLM，必须走接口

### 4.8 输入面板（语音输入 + 唤起行为修复）

#### 4.8.1 语音输入（P1）

- 输入面板（悬浮球/快捷键唤起的捕捉输入窗口）增加**语音输入按钮**
- **复用沉浸式输入的语音识别模型**（FireRedASR2，本地，无 Python 依赖）
- 交互：**点击开始录音，再次点击停止**，识别结果**追加**到输入框光标处
- 录音期间有视觉反馈（录音状态标识）
- **互斥**：沉浸式输入语音识别进行中，输入面板语音输入弹窗提示（"沉浸式输入正在进行语音识别"），不并发录音

#### 4.8.2 快捷键唤起修复（P1）

**当前问题**（用户反馈）：
- 快捷键唤起时键盘焦点未落在输入框，无法直接输入（须鼠标点击输入框）
- 快捷键唤起时点击外部区域不立即关闭；空内容时卡数秒才消失（依赖超时兜底）
- 悬浮球唤起无此问题 → 两条入口窗口行为不一致

**修复方案**：
- 窗口显示后主动 Focus 输入框 + **激活 IME**（中文输入法可直接输入）
- 统一关闭逻辑：失焦（Deactivate）立即关闭；无内容不保存；有内容按现有逻辑处理
- 快捷键唤起与悬浮球唤起行为统一

### 4.9 设置与个性化（P2）

#### 4.9.1 AI 助手名称自定义

- 设置页增加「AI 助手名称」输入框，默认值"AI 问答"
- 名称作用于：悬浮球右键菜单 + 灵感速览面板标题栏的 AI 问答入口文案（两处同步）
- **显示名与功能名分离**：内部功能仍为"AI 问答"，仅显示文案可自定义，不影响业务逻辑
- 名称长度限制（建议 ≤10 字符），防撑爆菜单

#### 4.9.2 任务栏/托盘图标自定义

**现状查证**：csproj 无 ApplicationIcon（exe 用 .NET 默认图标）；托盘图标（NotifyIcon）为代码生成的 32x32 纯深灰方块（`CreateTrayIcon`，0x3A3A3A 无图案）——即"黑坨"来源。

**需求**：
- 设置页「外观」区：上传图片（png/jpg，≤1MB）自定义**任务栏/托盘图标**
- 覆盖范围：运行窗口任务栏图标 + 系统托盘图标；**悬浮球图标不改**（保持代码生成）
- **exe 文件图标不随运行时修改**（编译期嵌入）；如需更换，重新编译即可
- 默认图标建议：为 v2.0 设计正式 .ico 替换深灰方块（未定，可后续排期）

## 5. 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 对话框流式输出，首 token 延迟感知 < 2s |
| 离线 | 无网络时 AI 功能不可用，需明确提示（无本地词典，无降级通道） |
| 隐私 | 设置页明示内容发送至用户自配模型服务；对话历史仅存本地 SQLite |
| 兼容 | 延续 v0.1.0 单文件绿色版分发（WPF .NET 8 self-contained） |
| 稳定性 | 网络异常/API 限流需有错误提示与重试，不得崩溃 |

## 7. 技术架构

```
WPF 客户端（.NET 8）
├── 灵感速览面板
│   ├── 笔记列表（只读 TextBlock / 编辑模式切换）
│   ├── 右键菜单（原生操作 + AI 三选项）
│   ├── 浮动工具条（编辑态选中触发，延迟 300-500ms）
│   ├── 顶部标题栏（AI 问答入口）
│   └── AI 对话框（流式消息列表 + 输入框）
├── AI 层
│   ├── IChatProvider（抽象：补全 + 流式 + tool calling 预留）
│   │   └── OpenAICompatibleProvider（实现）
│   ├── ITextExplainService（查词/解释抽象）
│   │   └── LlmTextExplainService（实现，走 Provider）
│   └── 对话管理（上下文裁剪、历史持久化 SQLite）
├── 配置（模型选择 + BYOK Key）
└── 悬浮球（右键菜单 + AI 问答入口）
```

## 8. 验收标准

1. 设置页可配置模型（Base URL + Key），可切换 Agnes/Hunyuan-lite，切换后对话正常
2. 笔记双击进入编辑、Ctrl+S 保存、Esc 取消；沉浸式锁定中的笔记编辑/回填均被拦截并弹窗
3. 非编辑态右键菜单含 AI 三选项 + 原生操作；编辑态选中文字延迟浮现工具条
4. 三个板块均可连续对话，流式输出正常；问答与翻译/搜索上下文互不串味
5. 单词选中 → 词典式释义；段落选中 → 整段翻译（动态适配生效）
6. 回填默认追加格式正确；覆盖需二次确认；沉浸式锁定笔记回填被拦截
7. 断网时 AI 操作有明确错误提示，应用不崩溃
