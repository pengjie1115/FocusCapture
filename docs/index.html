FEATURES

四个核心能力，一个都不打扰你

灵感稍纵即逝，FocusCapture 让你的捕捉成本降到最低。

桌面悬浮球

常驻最前层，可调不透明度。输入、速览、设置、语音、退出五大入口一键直达。

剪贴板自动捕获

复制即自动存为笔记。400ms 防抖过滤「选中即复制」类工具，自动去重，可随时开关。

沉浸式语音输入

纯 C# 本地语音识别，中英双语。边说边记，离线可用，无需联网、不上传音频。

本地优先，同步可选

笔记、设置、模型默认全存本机。需要多端同步？自行绑定坚果云 WebDAV，端到端加密，服务商也读不到内容。

PRIVACY

你的数据，只属于你

专注力工具处理的都是你的思想碎片，隐私是底线，不是卖点。

01 / LOCAL

默认 100% 本地

笔记库存放在「文档\FocusCapture」，配置文件在本机 AppData。卸载/删除目录即完全清除。可选 WebDAV 云同步（AES-256-GCM 端到端加密），授权码即钥匙。

02 / OFFLINE

语音离线识别

语音引擎纯 C# 本地运行。首次使用自动下载模型到本机，之后完全离线，音频不出你的电脑。

03 / OPEN

开源可审计

MIT 协议，全部代码公开在 GitHub。任何宣称的安全，都不如你自己能看到的代码可靠。

FAQ

常见问题

不需要。Release 提供单文件绿色版（self-contained），已内置 .NET 运行时，双击即运行。
首次使用语音输入时，程序会从国内可直连的镜像自动下载模型（约 740MB）到本机。下载完成后完全离线运行，音频不离开你的电脑。
默认完全本地。可选开启 WebDAV 云同步（AES-256-GCM 端到端加密），授权码即钥匙，即使服务商也读不到你的内容。
Markdown / JSON / TXT / Word（.docx）四种格式。时间、来源窗口、标签、内容字段可勾选，自动处理重名文件。
关注 GitHub Releases 页，下载新版 exe 覆盖即可。笔记与设置都会保留。
目前仅支持 Windows 桌面端（10 / 11 64 位）。更多平台在 Roadmap 规划中，欢迎在 GitHub Issues 提建议。
