## 五、环境与流程（接手者必读，血泪浓缩）

1. **沙箱 PowerShell**：执行策略 Restricted，每条命令前同条命令里 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force`；输出一律 `Out-File -Encoding utf8` 落 %TEMP% 再用 Read/grep 读（`>` 产 UTF-16，Read 读不了）。
2. **git 联网操作走 bash**；提交信息写 UTF-8 无 BOM 文件（`.git/FC_COMMIT_MSG`）+ `dev.ps1 commit`；**禁 `git add -A`**，只 add 自己改的文件；暂存后必查 `git diff --cached --stat`。
3. **日常动作全走 `tools/dev.ps1`**：build / test / test -Slow / ready / snap / commit / status。`dev.ps1 snap` **不会先编译**——改完代码先 `build` 再 `snap`，否则出的是旧界面（实测踩过两次）。
4. UI 改动必须出快照图人工判读（本轮 10c 第一版"数据重复两套 + 分组视图没打开"就是快照抓出来的）。
5. 工作区有一个**前序会话的未跟踪文档**（`docs/2026-09-23-待修复缺陷-会话同步解密异常未捕获.md`）——不是本分支产物，**别动它也别提交它**。

## 六、本轮新踩的代码坑（防重蹈）

| 坑 | 症状 | 规则 |
|---|---|---|
| DataTemplate 里用 `RelativeSource AncestorType` | 悬停一条全员高亮 | 条目自身状态一律 `Trigger SourceName` |
| ControlTemplate 两个并列子级 | MC3089 | 模板根只能一个元素（Grid 包一切） |
| `Button.Template` 与直接内容并存 | MC3000 | 内容进模板或模板只留 ContentPresenter（发送按钮用了后者——注意模板内 x:Name 不进窗口 NameScope） |
| `MenuItem` 子菜单弹出层 | 白底白字 | 系统模板的弹出层背景不是 TemplateBinding，改颜色无效，必须换模板 |
| `PromptDialog` Focus/SelectAll 时机 | 全选从不生效 | 必须 `win.Loaded` 之后 |
| 事件参数里可空 context 的语义 | `Group+null` 被解释成"移出分组" | 菜单父项（有子菜单的）绝不绑 Click |
| 并集同步 | 删除被云端复活 | 一切"删除"都要墓碑；`Load()`（UI 口径）与 `LoadAll()`（同步口径）分开 |
| `List<ChatSearchHit>` 接 `IReadOnlyList` | CS0266 | `Search` 返回 `IReadOnlyList<ChatSearchHit>` |
| Dispatcher.BeginInvoke 在 async 方法里 | CS4014 | `_ = Dispatcher.BeginInvoke(...)` |

## 八、验收口径（写给用户的现象级描述）

- 悬停任何一条：只有它高亮，别的纹丝不动
- 点「置顶此分组」：该分组行带着「置顶」徽标跳到分组列表最前（收藏之下）；再点「取消置顶」回原位
- 删除分组：消失后**无论同步多少轮都不回来**（另一端也消失）
- 会话「分组到…」：立刻从「最近」消失，点进对应分组能看到
- 分组视图里直接输入并发送：自动建会话归入该分组、退出分组视图、侧边栏收起、进入正常对话
- 重命名：弹框里是原标题且全选，可直接输入替换或局部修改
- 「分组到…」「导出」子菜单：深色底、浅色字，看得清
- 会话三点菜单里有「批量操作」：选中多条后底部出现 删除/移入分组/取消
- 加号、圆形绿色向上箭头发送按钮都在输入框内部；框下有「选择分组」
