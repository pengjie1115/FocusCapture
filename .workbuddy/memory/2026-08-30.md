**GitHub token 诊断（关键结论）**：
- 环境变量 `GITHUB_TOKEN` 存在（ghp_ 开头 40 位，格式正确）但 **API 返回 401 Bad credentials → 已失效**（过期或被 GitHub 自动 revoke）
- **github.com 主站不通**（HTTP 000，被墙/超时），但 **api.github.com 通**（token 有效时可走 API 做转公开/删分支）
- 无 SSH key（~/.ssh 不存在）→ SSH 通道也没有
- 结论：GitHub 侧操作（代码推送、转公开）卡在 ① 新 token（用户生成）② github.com 主站连通性
