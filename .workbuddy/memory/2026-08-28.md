## 待办时间识别 Bug 修复（v2 时间解析）

### 背景
创建/编辑待办的时间识别不准：汉字数字（八点/八点零三）、分钟写法（8点03）、指定日期（今晚/本月30号）全识别不了；识别错误时显示"第二天上午9点"（实际是 DueTimeDialog 预填默认值，非识别结果）。

### 根因（诊断结论）
1. TimeParser 规则写死只认阿拉伯数字（\d），汉字数字全军覆没
2. "X点Y"（无"分"字）分钟被吞成整点（正则 `(\d{1,2})点(半)?`）
3. 创建待办路径（NoteService.SaveNote）只有本地规则，**根本没接 LLM 兜底**——"大模型没兜住"的真相
4. 编辑路径 LLM 兜底两个坑：空 Key 也发请求（MainWindow 无条件 new provider）；JSON 解析只认裸 JSON 不认代码块
5. "明天上午9点" = DueTimeDialog.xaml.cs:17 预填默认值，不是识别结果

### 改动（分支 feature/todo-reminder-phase4，未动 main）
- **TimeParser.cs 重写**：两段式（时刻提取 + 日期上下文）。支持：汉字数字/分钟写法/全角冒号（8：03）/点·时·半·一刻·凌晨/今晚·明早·明晚（规范化拆词）/本月N号·裸N号·8月27号/大后天/下周三/下个月N号/半小时后·一个半小时后·一刻钟后。新增 ParseResult(Matched, Time, IsBareClock, IsDateOnly)
- **TodoEditService.cs**：新增 ResolveDueAsync 统一入口（未来直接用 / 纯日期弹"问几点" / 裸时钟已过弹三选一 / LLM 兜底空Key短路+剥代码块）
- **新增 TimeConfirmDialog**：裸时钟已过确认弹窗（今晚X点/明早X点/取消，深色风格）
- **DueTimeDialog**：加 prompt 参数（纯日期"问几点"复用）
- **NoteService.SaveNote**：加显式 dueTime 参数
- **InputWindow / QuickViewWindow / NoteEditWindow**：接入 ResolveDueAsync

### 用户反馈 4 件事
1. **来源筛选卡死**：点一下选中源就再点不动（截图：3 个来源弹出，无勾选标记；点了就立即"刷成该源"，看起来像单选）

4. **事件冒泡复制**：待办徽标点击会触发条目复制（已通过 e.Handled=true 解决）

### 根因（修真重点）
- **问题 1 真因**：`QuickViewWindow.xaml:393` Popup `StaysOpen="False"` → WPF Popup 检测到 popup 内元素处理 MouseDown 后焦点丢失 → 自动关闭。每次 ToggleSource → Children.Clear/重建 → 焦点丢失 → popup 关掉 → 用户体验"单选卡死"
- **问题 2 真因**：XAML 硬编码 `StringFormat=HH:mm`，没有"今天/跨天"分支
- **问题 3 真因**：`SetBadge` 无脑 Visible（不检 _isCollapsed）；`showDuePopups` 回调不调 ExpandBall；GetBallAnchor 隐藏态下弹窗坐标在屏幕边角看不到

### 改动（提交 b86d01b，4 个业务文件）
- **来源筛选 popup 修法**：`StaysOpen=True` + `Mouse.AddMouseDownHandler` 静态全局监听 → 检查 OriginalSource 是否在 SourceFilterBtn / SourceFilterPopup.Child 子树 → 否则关 popup（IsDescendantOf 沿 VisualTree 上溯）
  - PopupAnimation 由 Slide 改 Fade（避免 StaysOpen=True 时 Slide 不再 auto-open）
- **悬浮球提醒**：`FloatBall.ExpandBall()` 提为 public（复用 CollapsedBar_MouseEnter 逻辑）；`MainWindow.showDuePopups` 回调隐藏态时先 `ExpandBall()` 再弹窗
- **跨日期时间**：`NoteEntryViewModel.DisplayTime` 属性，today 只显 HH:mm、跨天 `MM-dd HH:mm`；XAML 两处时间绑定换 `DisplayTime`
- 数据结构：`_sourceFilter: string` → `HashSet<string>` 多选；删除 `_suppressSourceFilterEvent` / `_suppressSourceRebuild` 冗余
