### 根因（本次确认的唯一根）

**行 ID = SHA256(相对路径｜行文本)，而"相对路径"在系统内有三套口径：**

| 环节 | 口径 |
|---|---|
| 本地写入 `SaveNote` | 提醒日 → `灵感_{DueTime}.md` |
| 删除/编辑查找 `FindEntryFile` | 创建日 → 只查 `灵感_{Timestamp}.md` + 标签文件 |
| 跨端落地 `ResolveRelativePath` | 创建日（CreatedAt） |

→ 同一条行在不同设备/不同操作下落进不同文件 = 不同 ID ⇒ ①本机删不掉（找不到文件）②跨端删除不生效（墓碑 ID 对不上）③旧版本行被当"本机没有的新行"反复投递回本地（待办复活、副本每轮 +1）。
