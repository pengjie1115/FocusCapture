  不匹配的场景**连窗口都不构造**（快 + 少串扰共享 settings）；一个都没匹配时**以退出码 2 失败退出**。`c984507`

  `-List` 列出 45 场景；`-Only '03b,03c,03d'` 精确出 3 张；`-Only '10e'` 出 1 张；`-Only 'zzzz-nope'` 报错退出。`c984507`

**决策**
- **光加过滤不够，必须配 `--list`**：场景名↔代码板块的映射只活在 `UiSnapshot.cs` 的注释里，纯子串匹配
  会**静默漏图**（改「AI 功能」板块时 `03d-设置-AI 问答界面` 名字里根本没这四个字）。「能否按需出图」的
  答案是「能，但前提是先有清单」—— 否则不是按需、是按猜。关键字**用编号不用中文板块名**（编号稳定，
  不会被后续改名甩掉）。`c984507`
- **`--only` 一个都没匹配必须失败退出**：按需出图的致命失败是「漏了图却不知道」，安静地出 0 张
  等于把整个判读环节骗过去，比全量慢危险得多。`c984507`
- **分支从 `feature/ai-tidy` 开出**（用户拍板）：两条线都动 `UiSnapshot.cs` / `tests/Program.cs`，
  从 main 开必冲突；代价是本次提交叠在 AI 整理之上。`c984507`

**踩坑**
- **PowerShell 逗号 = 数组分隔符**：`-Only 03b,10e` 进来是三个元素的数组，绑给 `[string]` **参数绑定失败**
  → 脚本压根不执行、**零输出**，而 `$LASTEXITCODE` 还保留着上一次的值（看着像成功）→ 改收 `[string[]]` 再自己 join。`c984507`
- **PowerShell 数字后缀吃掉 `d`**：`03d` 被解析成 decimal `3`（`03b`/`03c` 因为 `b`/`c` 不是后缀而幸存），
  于是 `-Only 03d` 静默匹配到 10 张无关图（13/23/30 里都有 3）还报「已生成」成功 → 值加引号 + 加防呆
  （`-Only` 里出现「单个数字」直接报错，本项目编号无一位数、零误伤）。`c984507`
- 顺带修：脚本自己打印「对比法最有效（改动前后各跑一次）」，开头却把输出目录整个清空
  —— **建议与实现互相打脸**，第二遍跑完基线图就没了。时间戳目录解决的就是它。`c984507`
