# FocusCapture 功能一览

> 每个功能都围绕一条原则设计：捕获灵感的过程不能比灵感本身更长。

## 捕获

- **桌面悬浮球**：常驻屏幕最前层，不遮挡工作区；输入、速览、语音、设置、退出五大入口一键直达，不透明度可调。
- **剪贴板自动捕获**：复制即自动存为笔记。400ms 防抖过滤瞬态写入，自动去重，可随时开关。
- **全局热键**：不切窗口即可唤起输入窗、开关剪贴板捕获、打开速览、启动语音、唤起 AI 问答与待办汇总，热键可自定义。
- **沉浸式语音输入**：纯 C# 本地语音识别（sherpa-onnx + FireRedASR2），中英双语，深浅双主题，正文占比可调。识别全程离线，音频不上传。

## 整理

- **灵感速览**：最近笔记面板：今天 / 昨天 / 近 7 天 / 近 30 天 / 自定义区间筛选；标题栏按钮可自由组装；日历上绿点标注每天笔记数、橙点标注待办。
- **来源与标签**：自动记录每条笔记的来源窗口，支持打标签，导出时可选携带。
- **待办与提醒**：一句话记待办，自动解析到期时间；未到期待办在日历上有标注，到期弹提醒。
- **每日总结**：一键汇总当天笔记与待办，快速回顾这一天。
- **回收站**：删除的笔记先进回收站，可恢复，防误删。

## AI

- **AI 问答**：支持图文混排的 AI 对话窗口：截图直接 Ctrl+V 粘贴、Word/Markdown/PDF 文本自动抽取随消息发送。模型服务由用户自行配置（OpenAI 兼容接口），API Key 只存本机。
- **得到大脑集成**：可配置「得到大脑」开放平台凭证，笔记一键上传你的知识库。

## 带走

- **一键导出**：Markdown / JSON / TXT / Word（.docx）四种格式；时间、来源窗口、标签、内容字段可勾选；自动处理重名。
- **笔记导入**：从其他工具迁移：导入前有预览确认，不怕导错。
- **加密云同步（可选）**：支持 WebDAV 网盘同步笔记与待办，AES-256-GCM 端到端加密，授权码即钥匙。默认不同步，数据全本地。

## 默认热键

| 热键 | 功能 |
|------|------|
| Alt+Space | 唤起灵感输入窗 |
| Ctrl+Alt+F1 | 剪贴板自动捕获 开/关 |
| Ctrl+Alt+V | 打开/关闭 灵感速览 |
| Ctrl+Alt+R | 启动沉浸式语音输入 |
| Ctrl+Alt+A | 唤起 AI 问答 |
| Ctrl+Alt+T | 打开/收起 待办汇总面板 |
| Ctrl+S | 语音输入窗内保存 |

以上热键均可在「设置 → 热键」中修改。

## 数据存在哪

| 内容 | 位置 |
|------|------|
| 笔记库 | 文档\FocusCapture\ |
| 配置文件 | %AppData%\FocusCapture\settings.json |
| 语音模型 | %LocalAppData%\FocusCapture\models\ |

所有数据均在本机；卸载或删除对应目录即完全清除（开启云同步的用户，网盘侧副本需自行删除）。
